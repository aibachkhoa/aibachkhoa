专注

一个几乎不用碰的计时器。

所有操作都在时钟上完成。工作时没有任何菜单挡路。

用手势，而不是按钮

轻点开始或暂停。左右滑动跳过，上滑多加一分钟，下滑停止。在 Windows 上：使用空格键、方向键或鼠标滚轮。

一眼看清时间的圆环

圆环随时段推进逐渐填满，并随模式变色：专注为番茄红，短休息为绿色，长休息为蓝色。

按计划长休息

自定义长休息前要完成几个专注时段。时钟下方的圆点显示你还差多少。

保持心流

自动开始休息和工作时段，时段结束时收到通知——即使应用在后台运行也不会错过。

氛围

音乐与场景，让你沉浸其中。

工作时播放二十首专注音乐，随机不重复。标记你喜欢的曲目，它们会优先播放。

  • 自动背景随一天的时间变化：日出、白天、日落和星空之夜。
  • 也可以选择番茄、森林、夜晚、日出、白天、日落——或使用你自己的照片，并调节暗化程度。
  • 轻点一下即可静音或切歌，无需离开计时器。

统计

看见一整年的专注。

每个完成的时段都会被记录，让进步看得见，而不是靠猜。

年度热力图

过去一年每天一个方块，专注时间越长，颜色越深。

历史记录

按天、周或月查看时长或时段数，以及你效率最高的星期几和时间段。

彩色标签

按科目或项目为时段打标签，清楚看到时间都花在了哪里。

你的数据，你的文件

导出和导入备份，或将所有时段导出为 CSV，用电子表格查看。

Windows

一个不打扰你的玻璃小组件。

在 Windows 上，Flow 是一个圆角半透明的小窗口，可以固定在屏幕任意一角，工作时始终置顶。

  • 固定在角落或随意拖动；它会记住你上次放置的位置。
  • 对电脑负担很轻：空闲时约 0.1% CPU，运行时段时约 1%。
  • 键盘快捷键：空格键开始或暂停，→ 跳过，↑ 多加一分钟，↓ 停止。
