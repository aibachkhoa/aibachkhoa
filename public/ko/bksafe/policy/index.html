BKSafe — Windows, macOS, Linux, Android용

최종 업데이트: 2026년 11월 7일

요약

BKSafe는 베트남의 AIBachKhoa(Son Tran)가 배포하는 보호 및 관리 도구 모음입니다. Windows, macOS, Linux, Android의 네 가지 버전이 있습니다.

데스크톱 버전에는 로그인 계정도, 원격 측정도 없으며, 어떤 검사 결과도 외부로 보내지 않습니다. 모든 검사, 모든 수치, 모든 로그는 해당 기기에 그대로 남습니다. 개인 데이터는 Pro를 구매하거나 활성화할 때만 기기 밖으로 나가며, 이메일 주소, 컴퓨터 이름, 무작위 기기 식별자가 이에 해당합니다. 모두 아래에 설명되어 있습니다. Android 버전은 일부 운영 데이터를 수집하며, 이 역시 아래에 나열되어 있습니다.

데스크톱 버전 (Windows, macOS, Linux)

이 세 버전은 기기에 대해 많은 정보를 읽습니다. 그것이 이 앱의 역할이기 때문입니다. 하지만 그 무엇도 기기 밖으로 나가지 않습니다. 구체적으로 앱이 읽는 정보는 다음과 같습니다.

  • 하드웨어 수치: CPU, 메모리, 온도, 드라이브 상태, 네트워크 트래픽
  • 검사하도록 선택한 폴더 안 파일의 내용 (악성코드 여부 확인용)
  • 프로세스, 서비스, 드라이버, 시작 항목 목록
  • 운영체제의 보안 설정: 방화벽, 악성코드 방지, 드라이브 암호화
  • 저장 공간 측정 기능을 사용할 때의 폴더 이름과 크기

로그인할 계정이 없고, 사용 분석이나 오류 보고 기능도 들어 있지 않습니다. 파일 내용은 메모리에서 읽혀 시그니처와 비교된 뒤 폐기되며, 복사되거나 업로드되거나 보관되지 않습니다. 파일 이름, 경로, 해시, 검사 결과는 앱이 만드는 어떤 연결에도 포함되지 않습니다. 앱은 기기에 저장되는 무작위 기기 식별자를 생성합니다. 이 식별자는 하드웨어에서 파생되지 않으며 Pro를 활성화하거나 갱신할 때만 전송됩니다.

앱이 디스크에 기록하는 내용은 사용자 계정의 설정 폴더 안에 있습니다: 언어 선택, 라이트/다크 모드, 알림 임계값, 실행한 검사 기록. 라이선스 정보, 인증된 이메일 주소, 기기 식별자는 운영체제의 보안 저장소에 보관됩니다. 앱을 제거하고 앱 데이터를 삭제하면 기기에 보관된 모든 것이 제거됩니다.

데스크톱 버전이 외부에 연결하는 경우

데스크톱 버전은 아래의 연결만 만듭니다. 어느 연결도 사용자의 파일이나 검사 결과를 전송하지 않습니다.

연결 시점과 이유
악성코드 정의 업데이트 앱을 열 때 자동으로 실행되며, 완료된 확인은 하루에 최대 한 번입니다. 정의 서버에서 악성코드 정의를 다운로드합니다. 요청에는 식별자나 앱 이름이 포함되지 않습니다. 서버는 다른 웹 요청과 마찬가지로 사용자의 IP 주소만 볼 수 있습니다.
앱 업데이트 (macOS, Linux) 앱을 열 때와 12시간마다 aibachkhoa.com에서 작은 버전 파일을 읽습니다. 요청에는 앱 버전과 운영체제만 포함됩니다. 이 확인은 "자동 업데이트"가 꺼져 있어도 계속되며, 해당 스위치는 다운로드와 설치만 중단합니다. 새 버전이 있으면 설치 프로그램은 같은 서버에서 받습니다. 설치 중에 macOS는 공증 확인을 위해 Apple에 연결할 수 있으며, Linux에서는 패키지 관리자가 필요한 라이브러리를 다운로드할 수 있습니다. Windows 버전은 이 연결을 만들지 않습니다.
Pro 라이선스 서버는 당사의 라이선스 서버입니다. Pro 페이지를 열면 가격표를 불러옵니다. 서버는 결제 수단의 순서를 정하기 위해 IP 주소로 국가를 추정할 수 있습니다. 구매할 때는 인증 코드를 받기 위한 이메일 주소와 선택한 요금제를 보냅니다. 라이선스를 활성화하거나 수령할 때 앱은 무작위 기기 식별자, 컴퓨터 이름, 운영체제 이름을 보냅니다. 라이선스가 있으면 앱은 앱을 열 때와 12시간마다 라이선스를 새로 고칩니다. 아무것도 구매하지 않았다면 앱은 가격표 요청 외에는 이 서버로 아무것도 보내지 않습니다.
결제 결제를 선택할 때만 해당합니다. PayPal은 브라우저에서 열립니다. 계좌 이체의 경우 앱이 이체 QR 제공업체에서 QR 이미지를 불러오며, 사용자는 자신의 은행 앱에서 결제합니다. 카드 번호와 은행 정보는 절대 BKSafe를 거치지 않습니다.
운영체제 업데이트 확인 보안 화면에서 확인 버튼을 누를 때만 실행됩니다. 연결은 운영체제 자체의 도구가 만들며, BKSafe는 여기에 아무것도 추가하지 않습니다.

이 외에 데스크톱 버전은 다른 어떤 네트워크 연결도 열지 않습니다. 서버용 명령줄 패키지에는 앱 업데이트나 라이선스 구성 요소가 없으며, 요청되거나 예약된 경우에만 악성코드 정의를 다운로드합니다. 이 모든 것은 어떤 네트워크 모니터링 도구로도 확인할 수 있습니다.

Android 버전이 수집하는 정보

Android 버전은 서비스 운영과 위협 탐지를 위해 일부 데이터를 수집합니다.

  • 이메일 주소 및 사용 데이터
  • 기기 정보: 모델, OS 버전, 하드웨어 식별자, IMEI, Android ID
  • 앱 사용 빈도와 사용 시간, 수행한 작업
  • 충돌 로그 및 성능 지표
  • 위협 탐지를 위한, 검사한 앱의 패키지 이름

사진, 동영상, 연락처, 메시지 같은 개인 파일은 수집하지 않습니다. 단, 특정 기능을 위해 사용자가 명시적으로 접근을 허용한 경우는 예외입니다.

Android 버전이 요청하는 권한과 그 이유

권한 용도
MANAGE_EXTERNAL_STORAGE 저장소 폴더에서 악성코드를 검사하기 위해.
PACKAGE_USAGE_STATS 백그라운드에서 비정상적으로 동작하는 앱을 알아차리기 위해.
READ_CALL_LOG 수신 번호를 사기 번호 목록과 대조하기 위해.
VPNService 기기 자체에서 네트워크 트래픽을 모니터링하기 위해. 이는 기기 내에서만 이루어지는 로컬 연결이며, 어떤 트래픽도 당사 서버를 거치지 않습니다.

데이터 사용 목적

Android 버전이 수집한 데이터는 다음 목적으로만 처리됩니다.

  • 보안 위협 탐지
  • 앱 작동 방식의 개선 및 유지
  • 계정 관리
  • 법적 의무 이행
  • 필요한 경우 사용자에게 연락

데이터 공유

당사는 사용자 데이터를 제3자에게 판매하거나 공유하지 않을 것을 약속합니다. 예외는 세 가지이며, 숨기지 않고 여기에 밝힙니다.

  • 서비스 운영을 위해 당사가 위탁한 서비스 제공업체 (예: 분석), 그리고 그 업무에 필요한 최소한의 범위로만
  • 법률이 요구하는 경우의 관계 당국
  • 향후 합병 또는 사업 양도가 있을 경우의 인수 당사자

데스크톱 버전의 경우 기기 밖으로 나가는 유일한 데이터는 위에서 설명한 Pro 관련 정보입니다. PayPal과 계좌 이체 처리업체는 사용자가 결제할 때 각자의 정책에 따라 결제 정보를 받습니다. 검사 결과와 파일은 기기 밖으로 나가지 않으므로 그러한 종류의 공유할 것은 없습니다.

저장 및 보관

앱 활동에 관한 데이터는 사용자의 기기에서 처리되고 저장됩니다. 예외는 이메일 주소, 기기 식별자, 컴퓨터 이름을 포함한 Pro 주문 및 라이선스 기록으로, 이는 라이선스 서버에 보관됩니다.

앱을 제거하거나 앱에 내장된 삭제 기능으로 삭제할 수 있습니다. 데스크톱 버전에서는 앱 데이터를 삭제하면 앱이 기기에 기록한 모든 것이 제거되지만, 라이선스 서버의 기록은 제거되지 않습니다. 해당 기록은 라이선스가 유효한 동안, 그리고 회계 및 세법이 요구하는 기간 동안 보관됩니다. 나머지의 삭제는 이 페이지 하단의 주소로 요청할 수 있습니다.

아동의 개인정보

본 서비스는 13세 미만 사용자를 대상으로 하지 않습니다. 법률이 부모 또는 보호자의 동의를 요구하는 경우 당사는 그 요건을 준수합니다. 자녀가 당사에 정보를 제공했다고 생각되면 이 페이지 하단의 주소로 연락해 주십시오. 해당 정보를 삭제하겠습니다.

사용자의 권리

사용자는 자신의 데이터에 접근하고, 이를 정정하고 삭제할 권리, 그리고 당사의 처리에 이의를 제기할 권리가 있습니다. 요청은 이 페이지 하단의 이메일 주소로 보내 주십시오.

데스크톱 버전에서는 이러한 권리 대부분을 직접 행사할 수 있습니다. 기기의 데이터는 사용자 본인의 설정, 로그, 라이선스 정보이기 때문입니다. 서버의 Pro 기록에 대해서는 이 페이지 하단의 주소로 연락해 주십시오.

보안

데스크톱 버전이 기기에 보관하는 데이터는 운영체제 자체의 방어 수단, 즉 사용자 계정, 파일 권한, 보안 저장소로 보호됩니다. 데스크톱 버전이 Pro 구매를 위해 보내는 데이터와 Android 버전이 당사로 보내는 데이터에 대해서는 전송 중 암호화된 연결을 사용하며, 접근을 필요한 최소한으로 제한합니다. 완벽하게 안전한 시스템은 없으며, 당사도 그렇다고 주장하지 않습니다.

본 방침의 변경

본 방침은 앱이 바뀌면서 업데이트될 수 있습니다. 상단의 "최종 업데이트" 날짜는 항상 현재 유효한 버전을 나타냅니다. 데이터 처리 방식에 실질적인 영향을 주는 변경이 있을 경우, 이 페이지를 조용히 수정하는 대신 앱에서 알려 드리겠습니다.
